# Workflow and design guide

Read [WORKFLOW.md](WORKFLOW.md) when applying this guide to task execution or reviewing an agent workflow. It is the source of general execution principles for coding, research, and automation.

For UI design, improvement, or critique, read [DESIGN.md](DESIGN.md). It is the source of general visual and interaction design principles. Read both when the requested work involves both execution workflow and UI design; load only the relevant guidance for a focused review.

Apply the selected guidance within the requested scope and project instructions. For UI work, preserve the product's requirements, shipped behavior, and existing design system. A product's own `DESIGN.md` records product-specific decisions and is separate from this guide.

Handle focused improvements directly. For new interfaces or explicit redesigns, resolve the design intent and structural choices that materially affect the result before detailed styling. Use the project's existing tools and components; no additional CLI, package, framework, or mandatory research process is required.

Verify the task's observable result. For UI changes, review the rendered result and relevant states when available and authorized. Report the outcome, evidence, material reasoning, and verification limits briefly. This skill does not authorize GUI control, external publishing, or paid services.
